ABA Tracker v5 — Release Notes

What changed, what you need to do, and what to tell the RBTs.

Released October 2, 2026  ·  prepared for Tatiana (BCBA)

1. Prompt hierarchy — a level on every goal

Each goal card now has a dropdown next to it. The RBT picks the prompt level once per goal, per session — not once per trial. The ✓/✗ marks work exactly as before.

CodeLevelCodeLevel
IIndependentMModel
VTVisual / TextualPPPartial Physical
GGesturalFPFull Physical
VVerbal

The level records the level the goal is programmed to run at for that session — not a summary of what happened on each trial. That is what makes “one level per goal” accurate rather than an approximation.

  • It is required for any goal the RBT actually runs. Submit is blocked until it is set, and the app names the goal that is missing one.
  • Left blank means “not run today” — deliberately different from “needed no prompt”.
  • The order can be changed later with no loss of existing data, so if VT belongs elsewhere in your hierarchy, say so and it is a one-line change.

2. Probe checkbox

Beside the level there is a Probe checkbox. Ticking it sets the level to Independent and locks the dropdown — a probe is unprompted by definition, so the level is implied rather than being a second decision for the RBT. Unticking it clears the level, so an accidental tick cannot quietly record a goal as independent.

This separates clean measurement (a probe) from intervention (teaching trials). Teaching-trial accuracy is influenced by the prompt, by practice within the session, and by the therapist; a probe is the closest thing to a clean read of what the learner can do alone.

There is no separate “probe session” mode. Probes are identified only by this checkbox, so the RBTs need to be told to use it.

⚠️ 3. Goal mastery has changed — expect a pause

Goal mastery is now 80% for 5 consecutive sessions, at the Independent level. Sessions where the goal was not run are skipped, not counted as a break:

Independent → Independent → (not run) → Independent → Independent → Independent = MASTERED

A level that is recorded but is not Independent does break the streak.

What to expect: sessions recorded before this release carry no prompt level, so no new goal mastery will appear until five Independent sessions have accumulated for that goal — roughly five sessions from now. Nothing already marked mastered is affected. This is working as designed, but it will look like mastery has stopped if the team is not expecting it.

4. Automatic timestamps (nothing changes for the RBT)

The app now records the time each trial was scored, by itself, with nothing new on screen. This is what will later let trial data be lined up against session video, movement analysis and wearable signals. Without it, the finest possible match would be the whole two-hour session.

5. Parent behavior alerts

You can now have an email sent to a client’s parents when a behavior reaches a threshold you set. Found in the admin panel under Alerts (4th tab).

  • Per behavior you choose: alert on/off, the count that triggers it, and whether it sends automatically or waits for your approval.
  • Both parents can be listed. Each receives their own separate email — one parent never sees the other’s address, since custody and contact arrangements vary.
  • Nothing sends without consent on file. The client needs a recorded consent and a valid address, and consent is re-checked at the moment you approve — so a withdrawal between the session and your review is honored.
  • The email is deliberately brief: first name, date, behavior, count, and a request to contact you. No session notes, no ABC detail, no diagnosis. Ordinary email is not fully secure, so detail is kept to a minimum.
  • Available in English or Spanish per family.
  • Every send is written to the audit log as a disclosure, naming the recipient.

6. Discarding a practice session

A session opened just to try something out can now be removed without recording any data:

  • On the Select Client screen, each paused session has a red ✕.
  • During a session: Pause → Discard session.

Nothing is written to the client’s sheet, and the session cannot resurface later or send itself in. The discard is recorded in the audit log.

What we need from you

  1. Confirm the BAA covers Gmail. Alert emails go out through the practice’s Google Workspace. Until this is confirmed, test with your own email address only — not a real family.
  2. Choose the sending address (for example alerts@raising2gether.org) so alerts do not arrive from a personal account.
  3. Tell the RBTs about the two new controls — the prompt level dropdown and the probe checkbox. Their current written guide predates both.
  4. Warn the team about the mastery pause described in section 3.
  5. Confirm where Visual/Textual belongs in your hierarchy. It is currently placed between Independent and Gestural.
  6. Decide whether probes should be required for mastery. Today five Independent sessions count whether they were probes or teaching sessions run unprompted. Requiring probes is arguably stronger clinically, and is cheap to change now.

Worth testing before relying on it

  • ✓ Score a trial, leave the dropdown untouched, try to submit — it should refuse and name the goal.
  • ✓ Pause a session and resume it — the prompt level should still be there.
  • ✓ Tick Probe — the level should snap to Independent and lock.
  • ✓ Put two of your own addresses on one client, set one behavior to “wait for approval”, submit a test session, approve it — you should get two separate emails.

Not included in this release

Prompt level is not recorded per individual trial, and is not shown on the parent/caregiver view — both per your decisions. Backdated sessions entered by an admin do not capture a prompt level, so they are skipped when counting toward mastery.
