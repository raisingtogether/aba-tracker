What we want to add: today each trial is scored only correct (✓) or incorrect (✗). We propose capturing the prompt level the learner needed on each trial — so the data shows movement toward independence, not just accuracy. This is standard DTT data and is also the single most valuable signal for the future behavioral model. Before we build it, we need you to confirm the levels, the order, and how the percentage is calculated.

Proposed prompt levels (least → most support)

CodeLevelMeaning

GGesturalPoint/nod toward the answer

Order and set are a clinical choice — adjust freely (add Visual/Textual, remove any, reorder).

What this gives you

• Progress toward independence visible per goal over time (not just accuracy).  • Prompt-fading trends for programming decisions.  • Richer data for insurance justification.  • The key signal the behavioral model needs to predict which goals will master first.

Please confirm (or edit) before we build

  1. Levels & order: Is the 6-level set above correct, in this order? Add or remove any? (e.g., include Visual/Textual? separate No response from Error?)
  2. Percentage: Which should be the headline number on the trial screen — % Independent, % Correct (any prompted level counts), or show both?
  3. Mastery: Should goal mastery (currently 80% × 5 sessions) be based on % Independent going forward, or stay on % Correct?
  4. Required vs optional: Must the RBT pick a level on every trial, or may they leave it blank?
